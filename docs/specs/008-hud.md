# Spec 008 - HUD

**Status:** Implemented (2026-07-25)

> **Note (2026-07-25, updated 2026-07-26):** the *bag-pool* region below (bottom-right)
> is dropped by **Spec 009**. For the MVP the HUD is hearts (left) + the held-item box,
> now positioned on the **right** (not center); the 🔺/⭕ special slots are post-MVP. The
> held-item box's *behavior* is still as specified here — only its position changes.

## Goal

Minimal edge-pinned HUD per art-direction.md: player health + currently-held item. Presentation only — zero gameplay logic (game-architecture.md rule).

## Functional Requirements

- CanvasLayer instanced per room; central play area stays clean (Brawl Stars / Bomberman layout rule).
- **Layout (per Flavio's wireframe, 2026-07-25): a single bottom HUD bar.**
  - **Hearts — bottom-left:** 5 segments; lost health renders as darkened segments. No numbers.
  - **Held-item slot — bottom-center:** shows the drawn item's *picture* (appearance texture when the .tres has one; graybox color square until art lands) + small name. No next-item preview (team decision). Clears on throw and on trigger.
  - **Bag pool — bottom-right:** one square per item currently in the Bag's pool (MVP: Fire Orb + Right Hand of Ursula), rendered from the pool resource — adding an item to the pool updates the HUD with zero code.
  - The checkered play area + decorative border around it belong to the room scene / art integration (Silas), not the HUD.
- Listens to EventBus only (`player_damaged`, `item_drawn`, `item_thrown`, `item_effect_triggered`); reads player health via group lookup. Never calls gameplay methods.
- `EventBus.item_drawn` now carries the full `MagicItemResource` so the HUD can render color/name without hardcoding a catalog.

## Acceptance Criteria

- Taking a hit dims one heart immediately; entering the next room preserves the dimmed state (health persistence).
- Drawing shows the item swatch/name; throwing or detonation clears it.

## Out of Scope

- Countdown numbers (forbidden by design), enemy HP bars (forbidden), room progression indicator (post-MVP), final art/fonts.
